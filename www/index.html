AWS S3 Advanced Demo

Deployed via Terraform

Welcome to your Static Website!

This content is delivered directly from an Amazon S3 Bucket. The infrastructure responsible for serving this page demonstrates several powerful S3 features:

  • Static Website Hosting: Serving HTML, CSS, and JS serverlessly.
  • Versioning: Protecting against accidental overwrites and deletions.
  • Server-Side Encryption: Automatically encrypting object data at rest.
  • Access Logging: Capturing all requests to a separate log bucket for audit and analysis.
  • Lifecycle Policies: Automatically transitioning old logs to Glacier to save costs.

Infrastructure as Code

This entire stack was provisioned using Terraform. No manual steps were taken in the AWS Console.
